# JT Electric — sitio web

Sitio web estático y adaptable a móviles para JT Electric.

## Publicar gratis con GitHub Pages
1. En GitHub, crea un repositorio público nuevo llamado `jt-electric-web` (o el nombre que prefieras).
2. Sube `index.html` a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. GitHub mostrará la dirección pública cuando termine la publicación.

No reemplaces ni modifiques el repositorio de la aplicación JT Electric existente.
